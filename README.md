# SkyBlock Companion data

The pictures, maps and game data the [SkyBlock Companion](https://github.com/Skyblock-Companion/SBC) mod downloads, kept in one place so the mod stays small.

| Where | What | Source | Licence |
|---|---|---|---|
| `islands/` | Warp menu island pictures | [Hypixel SkyBlock Wiki](https://hypixelskyblock.minecraft.wiki) | CC BY-NC-SA 3.0 |
| `maps/` | Island map images | The wiki and [SkyGuide](https://github.com/DeDiamondPro/SkyGuide) | CC BY-NC-SA 3.0 / 4.0 |
| `remote.json` | Switches off a broken feature without a new release. It can only turn features off. | Made here | |
| `data` branch | Game data, updated daily | [SkyHanni-REPO](https://github.com/SkyHanniStudios/SkyHanni-REPO), [NotEnoughUpdates-REPO](https://github.com/NotEnoughUpdates/NotEnoughUpdates-REPO), [SkyblockAPI Repo](https://github.com/SkyblockAPI/Repo), [meowdding-repo](https://github.com/meowdding/meowdding-repo), [Hypixel API](https://api.hypixel.net) | MIT, and CC BY-NC-SA 4.0 for map data |
| `prices` branch | Lowest BIN prices, updated every 10 minutes | Hypixel's public auctions | Made here |

Nothing here holds data about players.
